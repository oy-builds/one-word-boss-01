# Circlebacker

A make.fun entry for "One Word for the Boss": exactly one word describing
the boss — no phrase, no caption, no explanation.

`main.ts` (Node 22, standard library only) writes the word to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

> Circlebacker

The boss who never decides anything. Every question gets "let's circle
back" and another meeting on the calendar. He doesn't decide, he doesn't
delegate, he just loops.

Run it with `node main.ts`.
